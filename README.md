## 🚀 Getting Started

This is a **header-only** library. Simply clone the repository and include the headers you need.

### Directory Structure
```text
├── leninsort.cpp
├── khrushchevsort.cpp
├── brezhnevsort.cpp
├── gorbachevsort.cpp
├── putinsort.cpp
└── README.md
```

### Compilation
Requires a compiler supporting **C++17** or higher (due to `std::variant` and `std::visit`).

```bash
g++ -std=c++17 main.cpp -o redsort_demo
./redsort_demo
```
